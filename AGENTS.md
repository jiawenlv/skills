# Personal skills

This repository is the canonical source for personally maintained skills under `skills/`. User-level discovery links live in `~/.agents/skills/`. Resolve links before editing and edit this repository, not a second installed copy.

Keep reusable decisions here and workspace-specific paths, renderer integration, secrets, course content, and learning evidence in their consuming projects. Preserve skill invocation policies. Use uv for Python environments and scripts.

Validate changed skills, local references, and applicable bundled scripts. Do not add third-party skills as original work; retain provenance and licenses for borrowed code. Do not overwrite installed skills without explicit user authorization. Reader development and course migration are separate tasks.
